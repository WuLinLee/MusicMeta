# 音笺 MusicMeta

一款轻量 Android 音乐整理工具：从网易云公开歌单或红心歌单选歌，也可以直接搜索歌曲；核对音源版本后下载，并尽可能补齐封面、歌词和音频标签。

> 当前开发版本：**1.01**（versionCode：7）  
> 应用包名：`com.wulinlee.musicmeta`  
> 支持 Android 10（API 29）及以上。

## 功能一览

- **两种歌单入口**：同步公开歌单；也可输入网易云用户 ID，尝试读取“我喜欢的音乐”列表。无需在应用里登录网易云账号，但私密或受限的列表可能无法读取。
- **左右滑动切换**：公开歌单与红心歌单可以左右滑动切换，也可以点上方标签切换。两边分别保留页码和滚动位置。
- **分页加载**：每页默认 25 首，可调整为 50 或 100 首；固定在屏幕底部的轻量分页条支持上一页、下一页、页码和 Enter 图标快速跳转。歌曲按页请求，避免同步时一次性拉取整份大歌单。
- **筛选和直接搜歌**：可以在已加载的歌单中按歌名或歌手筛选，也能直接输入关键词搜索音源，不需要先同步歌单。
- **候选版本对照**：歌曲行内的“找音源”会把候选版本展示在该歌曲下面，方便对照歌手、专辑和封面；直接搜歌使用相同的候选信息与下载操作。
- **多平台音源**：支持网易云和酷我候选搜索，下载前可选择 MP3 128 kbps、MP3 320 kbps 或 FLAC 无损。
- **整理音频文件**：支持自定义保存目录、文件命名方式、是否写入音频标签与歌词文件。下载到的音频不进行格式转码；实际返回格式与所选音质不符时会报错，不会假装转换成功。
- **封面与歌词补全**：尽可能写入歌名、歌手、专辑、封面、原文歌词及接口已有的翻译/罗马音/逐字歌词；缺失内容不会被凭空生成。
- **记住输入和偏好**：歌单链接、红心歌单用户 ID、音源平台、音质、每页数量和下载设置会保存到本地，普通清理后台后再次打开可继续使用。
- **内置下载站验证页**：如果来源站要求验证，可手动打开网页完成验证后重试。应用不会绕过验证码或访问控制。

## 快速使用

### 1. 加载歌单

选择“公开歌单”，粘贴网易云分享链接或歌单 ID，然后点击同步。想读取红心歌单时，切换到“我的红心歌单”，输入网易云用户 ID，再同步。

### 2. 找歌和选音源

在歌曲列表里点“找音源”，候选版本会展开在对应歌曲的下方。先核对**歌名、歌手和专辑**，再选择目标音质并点下载。同名曲目可能是现场版、翻唱版或不同母带，请不要只凭歌名判断。

不使用歌单时，可以在“直接搜歌”框里输入歌名或歌手并搜索，然后从结果中选择版本下载。

### 3. 选择音质和保存位置

在“下载设置”里设置默认音源平台、音质、命名格式、歌词和标签行为。主页面的“保存位置”可以选择系统允许访问的文件夹；应用会保存所选目录供下次使用。

### 4. 翻页和返回歌曲

底部分页条默认每页 25 首。可以改为 50 或 100 首，点页码或输入页码后按键盘 Enter / 底部 Enter 图标跳转。顶部 Home 图标用于定位歌曲列表开头，而非返回应用介绍区。

## 数据来源与 API 回退策略

应用通过公开接口获取信息，并不托管音源。网络服务可能限流、要求验证或调整接口，因此下表列的是代码当前使用的接口与备用路径；服务可用性不作保证。

| 用途 | 当前接口 / 服务 | 触发条件与说明 |
|---|---|---|
| 歌单详情和歌曲列表 | 网易云音乐公开接口：`music.163.com/api/v6/playlist/detail`、`music.163.com/api/v3/song/detail` | 首选路径。歌单先读取 ID 列表，再按页批量取歌曲详情。 |
| 红心歌单定位 | 网易云音乐：`music.163.com/api/user/playlist` | 根据用户 ID 查找“我喜欢的音乐”歌单；如果接口拒绝访问或歌单是私密的，可能无法读取。 |
| 歌单备用读取 | GD Studio：`music-api.gdstudio.xyz/api.php?types=playlist&source=netease&id=…` | 网易云歌单读取失败时尝试；不是每次都会调用。 |
| 搜索音源、解析下载地址、读取站点歌词 | `flac.music.hi.cn/ajax.php`，动作包括 `search`、`getUrl`、`getLyric` | 主音源接口。使用网易云或酷我平台参数。若站点需要验证，会使用应用内网页会话已有的 Cookie，不尝试绕过验证。 |
| 音源搜索/下载地址备用 | GD Studio Music API：`music-api.gdstudio.xyz/api.php`，如 `types=search`、`types=url` | 只有主音源搜索或下载地址解析失败时才尝试；下载兜底时会核对歌名和歌手，找不到可靠匹配就停止，以免误下其他歌曲。 |
| 歌词备用 | LRCLIB：`lrclib.net/api/get`、`lrclib.net/api/search` | 在主要歌词来源缺失时尝试；会核对歌曲名和歌手，优先使用同步歌词，接口无匹配时可能没有歌词。 |
| 封面备用 | GD Studio 图片接口、Apple iTunes Search API | 仅在已有歌曲封面无法取得时按顺序尝试。封面仍可能缺失。 |

**GD Studio 什么时候会用到？**  
它是后备来源，不是默认强制使用的下载源。主歌单接口读取失败时可回退到它；主音源解析下载地址失败时，也会重新检索并严格核对候选曲目。封面和歌词补全也会在主来源缺失时查询备用服务。备用接口同样可能不可用。

## 隐私与限制

- 歌单链接、红心用户 ID 与应用偏好保存在设备本地的应用设置中；这不是云端同步。**卸载应用可能清除这些数据**。
- 应用只承诺尝试读取公开或可匿名读取的数据。私密歌单、需要账号授权的内容不保证可用。
- 搜索和下载依赖第三方网站/接口；网络不可用、限流、站点验证或 API 改版都可能导致失败。
- 下载只接受标准 HTTP/HTTPS 音频地址，不处理网页内部的 `blob:` / `data:` 地址。
- 候选版本需要用户自行核对。请只下载自己有权保存的内容，并遵守来源站点条款和当地法律。

## 本地构建

需要：

- JDK 17
- Android SDK Platform 35 和 Build Tools 35.0.0
- Gradle 8.9

运行单元测试并构建 Release 变体：

```bash
gradle --no-daemon :app:testDebugUnitTest :app:assembleRelease
```

本地生成的 Release APK 默认未签名，路径为：

```
app/build/outputs/apk/release/app-release-unsigned.apk
```

GitHub Actions 会执行测试与 Release 构建，再进行 APK 对齐和签名。发布流水线每次使用临时签名密钥，因此不同发布产物的签名不相同。安装此类新版前，需要先卸载旧版；卸载可能清除本地数据。不要将 APK 签名理解为可直接覆盖安装的长期签名渠道。
